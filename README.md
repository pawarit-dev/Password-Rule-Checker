# JavaScript Password Rule Checker

A JavaScript password checker that validates the following rules:

- At least 8 characters long
- Contains at least one number
- Contains at least one uppercase letter

## Usage

Run the file with Node.js:

```bash
node passRule.js
```

The `validatePassword` function returns an object containing `valid` and a list
of `failedRules`.
